## Git: Pulling and Pushing

- Get the latest changes from GitHub before you start working:
	```bash
	git pull origin main
	```
- Check which files you have changed:
	```bash
	git status
	```
- Stage your changes to include them in a commit:
	```bash
	git add .
	```
- Save a snapshot of your staged changes with a short message:
	```bash
	git commit -m "Describe your changes"
	```
- Send your commit to GitHub:
	```bash
	git push origin main
	```

Pull again before starting work with teammates' latest changes. If Git reports a conflict, resolve it before committing and pushing.
